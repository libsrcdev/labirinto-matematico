EMULATOR PROVENANCE — WORKING LEGACY BUILD

Runtime identity
The working player uses the official Boxedwine legacy browser distribution under
https://www.boxedwine.org/boxedwine/build/default/
The server dates the JavaScript/WASM files to 2020-05-03. It does not publish an
exact source commit for those deployed binaries. This is NOT Boxedwine 26R1.
manifest.json records the exact source URL, size and SHA-256 of every runtime file.
scripts/prepare-runtime.py verifies those locked digests before packaging.

Local integration and original game
The host page and emulator.js are local integration code. The EXE and saves stay
inside the tab's memory filesystem; there is no upload service. labirintos.zip
contains only the original Labirintos.exe, unchanged. Its SHA-256 is
f9d80e450356039c42060389120ba4ff2cbf7f320896db149c39edaa869f3a53
The original game/art assets retain their authorship, credited in the title
artwork to Roque Anderson — Softwares Educativos. Emulator mode applies no game
hacks. Recreation-only speed and easy-calculation options do not patch the EXE.

Observed compatibility
The original menu rendered in Chrome; Enter started its original maze. The original maze and keyboard movement were also observed; a full seven-stage
playthrough has not been verified.
Original MIDI soundtrack output has not been verified. Browser audio activity
alone does not distinguish WAV effects from MIDI playback. The recreation's
separate Web Audio music implementation was tested independently.
